# Limbo Fit 1.4.0

Installable local fitness diary for Android APK, iPhone Home Screen and other browsers.

Calendar workouts, exercise history, Body (weight, custom measurements and body-fat history), profile and birthday-based age stay on the device. Trainer mode keeps a separate diary, phone and comment for each manual client. This release does not load the unfinished account, email or online-sync modules.

Public files only: no user records, backups, credentials, signing material or test fixtures.

Open the site in Safari, wait for the offline-ready status and add it to the Home Screen. Preserve a backup before clearing site data or removing the application. Update the APK over the existing app without uninstalling it.

The offline shell revision is 1.4.0. PWA readiness is verified by the worker cache handshake. The native APK skips PWA registration because its shell is already packaged.
