# Limbo Fit

Static, installable fitness diary for iPhone and other browsers.

Profile, weight history, exercise history, and calendar workouts are stored only in the current browser on the device. Trainer mode keeps a separate diary, phone number, and comment for each client.

This repository contains the public application files only. It does not contain user records, backups, Android signing material, hosting credentials, or test fixtures.

Open the published site in Safari, wait for the offline-ready status, and add it to the Home Screen. Save a backup before clearing browser data or moving to another website address.

The offline shell revision is 1.2.1.
